feat: Comprehensive security overhaul and bug fixes

Major security improvements and critical bug fixes across the entire application.
This update addresses SQL injection vulnerabilities, XSS risks, and fixes broken
delete operations while improving code maintainability.

## 🔒 Security Fixes

### SQL Injection Protection
- Replaced string concatenation with prepared statements in all 26 PHP files
- Implemented parameter binding for all database queries
- Added input validation and sanitization using trim()
- Prevented SQL injection attacks across insert, display, delete, and search operations

### XSS Protection
- Added htmlspecialchars() to all user-facing outputs
- Sanitized all dynamic content in display pages
- Protected against cross-site scripting attacks in search results

### Centralized Configuration
- Created config.php for database credentials management
- Created connection.php for centralized database connection handling
- Removed hardcoded credentials from all 26 PHP files
- Set UTF-8 character encoding for database connections

## 🐛 Critical Bug Fixes

### Delete Operations (MAJOR FIX)
- Fixed critical bug where delete operations were NOT actually deleting records
- Delete files were only checking if records existed, not removing them
- All 6 delete files now properly execute DELETE queries
- Added success/error feedback messages for delete operations

### HTML Structure
- Fixed invalid HTML structure in FrontEnd.html
- Removed duplicate <head> and <body> tags
- Consolidated all <style> blocks into single <head> section
- Corrected tag nesting and closing order
